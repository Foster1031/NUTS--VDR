Adding documents

Easiest: in "Add document," click the upload box and pick a file — it's stored right here on the site and everyone can download it directly. Good for files under 20MB.

For bigger files (long videos, huge archives), link out to Google Drive or Dropbox instead. Two minutes, tops.

📗 Google Drive

  1. Upload your file to Drive (drag it into drive.google.com).
  2. Right-click the file → Share.
  3. Under "General access," change Restricted to Anyone with the link (leave as Viewer).
  4. Click Copy link, then paste it into "Add document" here.

📘 Dropbox

  1. Upload your file at dropbox.com.
  2. Hover over the file → click Share (or Copy link).
  3. Make sure the link setting is Anyone with this link can view.
  4. Copy the link and paste it into "Add document" here.

Tip: name files clearly (e.g. NUTS-budget-v3.xlsx) so the list stays tidy.
